Needs your attention

How does this console work?
  • Tickets — a user asked the assistant for help from a person and confirmed it. Contact them, then press Start working and later Mark resolved.
  • Unanswered questions — things users asked that the documents don't cover. Press Needs a document so the data team writes it (download the list for them).
  • Disliked answers — answers users rated 👎. Check the answer; if a document is wrong, press Needs a document.
  • Security — attempts the assistant blocked (for example asking for passwords). Nothing to do unless one person repeats it.
  • System health and Activity log — for IT: speed, errors, cost and a permanent record of every question.
